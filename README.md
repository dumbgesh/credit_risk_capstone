# Credit Risk Capstone

A learning project focused on credit-risk fundamentals and the development of a credit-risk analysis workflow.

## Project status

This repository is being built incrementally. The current starting point is [`notebooks/01_credit_risk_fundamentals.ipynb`](notebooks/01_credit_risk_fundamentals.ipynb).

## Getting started

1. Clone this repository.
2. Open the notebook in Jupyter Notebook, JupyterLab, or VS Code.
3. Run the cells from top to bottom and install any dependencies requested by the notebook.

## Project goals

- Document core credit-risk concepts.
- Build the analysis step by step as the project develops.
- Keep research notes and practical work organized and reproducible.

This is an educational project; outputs should not be treated as financial advice or as a production credit-decision system.
